一、游戏与本地数据

当前版本没有游戏账号注册、云存档或游戏内实名认证功能。开发者没有设置用于接收游戏存档的服务器。

  • 进度：金币、角色和武器解锁、选择的角色与武器、武器升级、关卡解锁及关卡检查点。
  • 设置：按键位置、大小与隐藏状态，操作灵敏度、视角选项、音量及教程完成状态。

这些数据通过 Unity 的本地存储机制保存在应用私有区域，用于恢复进度和设置；游戏代码不会将这些存档发送给广告 SDK。设备清除应用数据或卸载应用后，进度可能无法恢复。

如果您主动通过邮箱联系我们，我们会处理您提供的邮箱、问题描述及您自愿提交的附件，用于回复和处理请求。请勿发送密码、广告媒体密钥、身份证件或其他与问题无关的敏感资料。

二、可选广告与第三方 SDK

当前只接入玩家主动选择的激励视频，用于“支持作者”或符合条件时的“额外救援”。没有开屏广告，不在启动游戏时自动播放广告。广告加载失败、拒绝同意或取消观看，不影响继续普通游戏；额外救援以 SDK 返回有效的奖励验证结果为准。

TapADN SDK（Dirichlet Ad SDK），当前 Android SDK 版本为 5.3.0.1。

TapADN SDK 隐私政策

广告功能涉及的信息

  • 设备与标识：品牌、型号、系统版本、屏幕参数、语言、时区、CPU、可用存储空间，以及 OAID；在设备和系统允许时，可能涉及 AndroidID、AAID、VAID。
  • 网络：IP 地址、网络类型、Wi-Fi 状态、信号强度；在系统允许时，可能涉及 Wi-Fi 接入点信息（SSID、BSSID）和设备 MAC 地址。
  • 应用与运行：应用包名、版本、前后台状态、运行进程，以及系统允许查询到的应用安装信息。当前版本不申请读取全部已安装应用的权限。
  • 交互与诊断：广告展示、播放、点击、转化及奖励结果，崩溃和性能数据。
  • 传感器：在设备支持时，SDK 可能使用加速度、陀螺仪、线性加速度、磁场或旋转矢量数据，用于广告交互或反作弊。

实际可取得的数据受 Android 版本、设备能力和系统限制影响。游戏不向 SDK 提供自定义用户账号 ID，也不申请读取电话状态或定位权限，不通过这些权限读取 IMEI 或 GPS 位置。移除定位权限不代表 SDK 无法通过 IP 等网络信息推测大致地区。

个性化广告推荐已通过 SDK 设置关闭。游戏也关闭了摇一摇交互；这不等于所有广告统计、设备信息或反作弊处理都已关闭。上述范围仍需您阅读并同意。

当前没有另行接入第三方广告聚合网络。TapADN 政策中列出的其他广告网络，不代表它们都已被安装到本游戏。

三、系统权限

当前 Android 构建包含以下权限。网络等普通权限由系统在安装时处理；声明权限并不表示可以绕过 Android 的授权限制。

INTERNET · 网络访问
连接广告服务、获取广告素材并发送广告相关请求。
ACCESS_NETWORK_STATE · 网络状态
判断网络是否可用及网络类型，处理广告加载。
REQUEST_INSTALL_PACKAGES · 请求安装应用
广告 SDK 的应用下载类广告可能使用此能力。安装其他应用需要您的主动操作及系统确认；您可以在 Android 的“安装未知应用”设置中保持不允许。
com.asus.msa.SupplementaryDID.ACCESS、freemme.permission.msa
广告 SDK 声明的部分厂商广告标识接口权限，在支持的设备上用于取得设备广告标识。

当前版本不申请电话状态、精确或粗略定位、读取全部应用列表、相机、麦克风、通讯录及外部存储读写权限。

四、保存与安全

  • 本地存档：保留在设备的应用私有区域，直到您清除应用数据或卸载。游戏使用备份与校验帮助减少意外存档损坏；校验不是加密。
  • 广告数据：由 TapADN 按其隐私政策保存和保护。其政策说明，境内运营产生的个人信息存储于境内，并在提供服务所必需的期限内保存，之后依法删除或匿名化。卸载游戏不能自动删除服务端已经保存的广告数据。
  • 联系记录：仅用于解决您提出的问题，在处理请求所必需的期间保存；不再必要时删除或匿名化，法律另有保存要求的除外。

我们采取与当前功能相适应的访问控制和数据最小化措施，不在公开网页或日志中披露 SDK 密钥。请同时保护好您的设备；互联网通信和存储不能保证绝对安全。

五、共享与外部链接

开发者不会出售您的本地游戏存档。广告功能中，TapADN 会按上述目的自行处理相关信息，并可能按其隐私政策与广告主、监测及服务合作方共享必要信息。我们会在需要时协助您联系 SDK 服务提供方处理相关请求。

您点击广告后访问的外部网站、下载的应用，或主动填写的广告表单，由对应服务提供方按其规则处理。请在提交信息前阅读对方的隐私说明。

本隐私页面托管于 GitHub Pages，页面本身不加载统计脚本、外部字体或广告。访问时，托管平台可能处理 IP 和访问日志，详见 GitHub 隐私声明。

六、您的选择与权利

  • 拒绝广告：不点击广告入口，或在广告同意页面取消。拒绝不会阻止普通游戏。
  • 撤回广告授权：当前版本尚无单独的会话内撤回开关。您可以退出游戏并重新启动，在广告同意页拒绝，且不再发起广告请求。广告同意只保留在当前游戏会话，不永久保存。仅取消一次观看不能保证已经初始化的 SDK 立即停止全部处理。
  • 清除本地数据：可在 Android“设置 → 应用 → 海岸行动 → 存储”中清除应用数据，或卸载游戏。不同设备菜单名称可能不同；此操作会清除游戏进度与设置。
  • 查阅、复制、更正、删除及投诉：请发送邮件至 kmhuixing@163.com。我们会核实并处理合法请求；涉及广告 SDK 服务端的数据时，会协助联系对应服务提供方。

撤回授权不影响撤回前基于您同意已经发生的处理。我们不会要求您提供与核实请求无关的资料；本地存档没有上传给开发者，相关导出或问题排查可能需要您自愿提供对应数据。

七、未成年人保护

未成年人应在监护人指导下阅读本政策。不满十四周岁的用户应由监护人协助处理个人信息相关事项；请监护人不要为儿童开启可选广告功能。

如果您是监护人，并认为游戏或广告服务在未获得适当同意的情况下处理了儿童的个人信息，请通过联系邮箱告知我们，我们将核实并协助停止相关使用、删除数据或联系 SDK 服务提供方。

八、更新与联系我们

如果游戏功能、第三方 SDK 或信息处理范围发生变化，我们将更新本页面和更新日期。需要重新取得同意的变更，将在相关功能使用前进行提示并征求同意。
